📲 Install on iPad/iPhone

1. Tap the Share button in Safari (the square with an arrow).

2. Scroll down and tap "Add to Home Screen".

3. Tap Add — the game will appear as an app icon!

🌐 Full app install

This game can be added to your home screen right from the browser share/menu on most devices.

For a full one-tap "Install" button (like a real app store install) on Android/Chrome, the file needs to be hosted online rather than opened locally — for example via GitHub Pages, Netlify, or Vercel. Happy to help set that up if you'd like!
